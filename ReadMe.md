# Atoll — установка

Нужен MacBook с чёлкой и macOS 14.6 или новее.

1. Если у вас стоит официальный Atoll или другое приложение для чёлки (Boring Notch, DynamicNotch и т. п.), закройте и удалите его: два таких приложения одновременно мешают друг другу.
2. Откройте `Atoll-<версия>.dmg` и перетащите Atoll в «Программы». Запускайте только оттуда, а не прямо из DMG.
3. При первом запуске macOS скажет, что не может проверить разработчика: сборка не нотаризована Apple. Нажмите «Готово», затем откройте «Системные настройки» → «Конфиденциальность и безопасность» и внизу нажмите «Всё равно открыть».
4. Если macOS пишет, что приложение «повреждено», выполните в Терминале и запустите Atoll ещё раз:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Atoll.app
   ```
5. Разрешите всё, что macOS спросит при первом запуске (Bluetooth, Календарь, Универсальный доступ и другие). Пока хотя бы один запрос висит без ответа, остров не работает.

Автообновление в этой сборке выключено. Чтобы обновиться, установите новый DMG поверх старого: разрешения сохранятся.
